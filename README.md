### 🌟 Featured Project

<table>
<tr>
<td width="100%">

**[Ehulak.tech](https://ehulak.tech) — Distributed Email Delivery Platform**

An API-first email delivery platform enabling apps to send and track emails through a reliable
`queue → worker → inbox` pipeline. Built with an event-driven architecture using **Kafka** and
**Redis (BullMQ)** to decouple services, with SMTP connection pooling, rate limiting, retries, and
Dead Letter Queue (DLQ) recovery for fault tolerance. Containerized with Docker and deployed
behind Nginx with real-time delivery tracking.

`AWS EC2` `Node.js` `Kafka` `Redis` `BullMQ` `Docker` `Nginx` `MongoDB` `SMTP`
